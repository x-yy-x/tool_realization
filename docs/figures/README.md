# L1–L4 流水线示意图

主文件：`l1-l4-pipeline.pptx`（16:9，13.333 × 7.5 in）

- 全部为 PowerPoint 原生形状：圆角矩形、文本框、直线连接线，**没有嵌入图片**。
- 每个 S 节点、提取器、验证器、chip 都是独立形状，文字、颜色、位置可以直接在 PowerPoint 里改。
- 五个分区：输入源码树 → L1 扫描/分类 → L2 提取 → L3 验证 → L4 修复；L4 虚线回环到 L1/L2/L3。
- L1 的 `遍历 → 识别 → 分类` 在同一水平线上，整体居于 L1 正中；`分类` 向右接竖直总线，再分 7 条箭头到右侧的 S1–S7。
- L3 为 5 个验证器：`V-tree`、`V-exists`、`V-identity`、`V-consistency`、`V-reach`。

## 重新生成与自检

依赖：`python-pptx`、`Pillow`（当前环境已验证）。

```powershell
py -I make_l1_l4_pptx.py
py -I check_l1_l4_pptx.py
```

`check_l1_l4_pptx.py` 检查：越界、文字溢出、长 token、节点重叠、是否嵌入图片。
通过时输出 `problems (0)`，退出码 0。

## 编辑提示

- 修改 chip 文字时尽量保持短标签；长标签在生成器里用 `\n` 换行。
- 若移动分区，保持 L2 七条泳道与 L1 的 S1–S7 节点中心对齐；生成器里由 `LANE_CENTERS` 统一控制。
- 配色：L1 蓝 `#2563EB`、L2 青 `#0D9488`、L3 琥珀 `#D97706`、L4 红 `#DC2626`；状态用绿 `#16A34A`。
- 画布坐标以英寸为单位；所有几何常量在生成器开头集中定义，改一处即可整体平移。
