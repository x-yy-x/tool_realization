# `src/common/` — 多层共用

**设计文档**：[`src/README.md` §16](../README.md)

**这个目录不属四层中的任何一层。** 它放的是「被多个层读」的东西——放进任何一层的目录都会让那一层多背一份别人的职责。

| 文件         | 被谁读                              | 职责                                                       |
| ------------ | ----------------------------------- | ---------------------------------------------------------- |
| `rules.py` | L2 / L3 / L4                       | 规则库加载与匹配（`knowledge.yaml` / `whitelist.yaml` / `arch_map.yaml`） |
| `probe.py` | L3 的 `v_reach` + `precheck/`   | 探测原语：DNS / 连接 / 权限，**统一带超时**        |

**`probe.py` 是 [`../precheck/`](../precheck/) 能当「没有 L2 的四层」用的原因**——第 -2/-1 层和 L3 用的是同一套探测原语，只是探测目标不同。

**改 `rules.py` 的接口要三层一起确认。** 它是三层的共用依赖，不是某一层的私产。
